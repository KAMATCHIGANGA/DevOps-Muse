Starcourt is a practice e-commerce website hosted on Amazon Web Services (AWS), integrated with RESTful APIs in the backend to handle user authentication, product management, shopping cart operations, and order processing. Deployments are automated through CI/CD pipelines, with an integrated alerting system for service and application issues. It also features an AI-powered agent, STAR AGENT, designed for proactive service monitoring and intelligent alert analysis.
